# Day Trader skills

The `trader-*` folders here are the 11 skills from
https://github.com/Jakeschincariol/day-trader-skill (commit 3d0f4ef6986f4984b7c6bd46f7ff4f87744c3abd),
copied in so they load in every Claude Code session on this repo.
MIT licensed, see DAY-TRADER-LICENSE.

The skills write their working files (config, plans, orders, portfolio) to
`trader/` in the project root. That folder is git-ignored so personal data
is never committed.

To update: re-clone the upstream repo and copy its `trader-*` folders over these.
